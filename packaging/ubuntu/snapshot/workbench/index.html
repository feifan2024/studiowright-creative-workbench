01

请求准备

调用地址是 http://127.0.0.1:18922。远程连接时需保持算力中心的端口转发。请求带 Authorization: Bearer <算力中心密钥>；JSON 用 application/json，文件原始字节用 application/octet-stream。

提交对话、识图或生成前，用 Idempotency-Key 传入并保存一个 UUID。超时或返回 unknown 时用原编号查询，不能换新编号重发。

GET/health统一 API 存活检查，不需要密钥；只说明 18922 端口可访问。
GET/api/health带密钥读取 API v1、部署信息和请求策略。
GET/api/snapshot读取 flow_models、tasks、real_accounts 和可用状态；提交前重新读取。

状态处理：200/201 表示查询或创建成功，202 表示已排队，400/401/403/404/409 表示请求或状态问题，502/503 表示上游暂时不可用。连接超时、502、503 或 unknown 都要保留原编号查询，不能重复生成。

Python 公共准备 · 先设置 STUDIOWRIGHT_API_KEY
import json, os
from pathlib import Path
from uuid import uuid4
from urllib.request import Request, build_opener, ProxyHandler

BASE = "http://127.0.0.1:18922"
AUTH = {"Authorization": "Bearer " + os.environ["STUDIOWRIGHT_API_KEY"]}
HTTP = build_opener(ProxyHandler({}))

def call(path, payload=None, request_id=None, *, file=None):
    headers = dict(AUTH)
    body = None
    if request_id:
        headers["Idempotency-Key"] = request_id
    if file is not None:
        headers["Content-Type"] = "application/octet-stream"
        body = Path(file).read_bytes()
    elif payload is not None:
        headers["Content-Type"] = "application/json"
        body = json.dumps(payload).encode("utf-8")
    with HTTP.open(Request(BASE + path, data=body, headers=headers), timeout=180) as res:
        return json.load(res)

Gemini · 对话与推理

POST/api/conversations传 title，返回对话 id。
POST/api/real-pool/chat传 conversation_id、account: "auto"、prompt，返回 request_id 和 status。

文字对话可选择 gemini-4-neon、gemini-4-hydrogen 和 gemini-3.8-flash。Neon、Hydrogen 的 effort 支持 low、medium、high、xhigh，默认 high。Flash 支持前三档，默认 medium。也可直接传完整型号，如 gemini-4-neon-xhigh。

新对话首轮使用 account: "auto" 时，可加 fallback_model。只有高级池在发送前无可用账号时，才改用指定的 Flash 型号。查看返回的 requested_model、实际 model 和 fallback.used。两个池都不可用时，入队前返回 HTTP 409，入队后按原编号查询失败原因。

续聊沿用实际绑定的模型系列和账号，允许修改同系列的思考等级。部分回复或结果未知时按原请求编号查询。高级池可派发账号数和共享额度见「总览 → Gemini 各账号额度」。

复制文字请求 · 实际发送
chat = call("/api/conversations", {"title": "我的对话"})
rid = str(uuid4())
print("请求编号:", rid, flush=True)
print(call("/api/real-pool/chat", {
    "conversation_id": chat["id"], "account": "auto", "prompt": "请用一句话介绍你自己。"
}, rid))
复制高级模型请求 · 允许降级到 Flash
chat = call("/api/conversations", {"title": "高级模型与 Flash 降级"})
rid = str(uuid4())
print("请求编号:", rid, flush=True)
print(call("/api/real-pool/chat", {
    "conversation_id": chat["id"], "account": "auto",
    "prompt": "请列出这个方案的三个关键风险。",
    "model": "gemini-4-neon", "effort": "xhigh",
    "fallback_model": "gemini-3.8-flash-medium"

04

Flow · 生成图片或视频

POST/api/real-pool/flow传 kind、confirm: true 和 params。返回 request_id、status、task_id；submitted 表示已排队。

Flow 确认接收视频后释放派发名额，其他账号可以继续上传和提交。同账号依次处理自己的任务，已提交视频由算力中心跟进并下载。提交后保留原 task_id，可继续提交新请求并轮询前一条的结果。

图片在 params 里填写 prompt、model、aspect、count；视频额外填写 resolution、duration。模型 ID 从快照取。时长按模型区分：Omni 1.1 Flash 为 4/6/8/10 秒，Omni 1.2 Flash 为 3～15 秒连续可调；画面比例 16:9 或 9:16。账号和项目由算力中心安排；积分按 Flow 实际报价计费，平台不设单笔上限。单图或单视频在请求顶层传 "auto_retry": false 后只尝试一次。

复制纯文字生成请求 · 实际提交
rid = str(uuid4())
print("请求编号:", rid, flush=True)
payload = {
    "kind": "image",  # 生视频时改为 video，并补上 resolution 和 duration；首尾帧参考见下方"带参考素材"
    "confirm": True,
    "params": {"prompt": "一张清晨海边的照片", "model": "填写快照中的模型 ID",
               "aspect": "16:9", "count": 1}
}
print(call("/api/real-pool/flow", payload, rid))

带参考素材

POST/api/real-pool/flow-references/auto/{素材 UUID}/{扩展名}逐个上传文件原始字节，返回 reference_id。上传、校验和提交使用同一个 Idempotency-Key，不填账号或项目。
模式在 params 中添加
图生图mode: "image-to-image" 和 reference_ids（图片编号数组）
Omni 首帧或首尾帧mode: "frames"、start_reference_id，可选 end_reference_id（图片编号）
Omni 混合参考model: "omni-flash-1.1"、mode: "ingredients" 和 reference_ids（图片、MP4 编号数组）

参考文件支持 JPG、PNG、WebP 和上述模式允许的 MP4，不接收独立音频。单文件最多 8 MiB、合计 64 MiB，编号 24 小时有效。单图或单视频由平台统一启用换号重试，最多换 3 个账号；重试行为不受调用方控制。图片只在确认未发送时重试；视频重试沿用原任务的时长与清晰度。结果不明不重发。查询和下载始终用原任务编号。只校验时发送 POST /api/real-pool/flow-validate 并设 confirm: false，返回 valid、submitted: false 和 reference_count。

05

音乐生成与音频

在 18922 端口提交音乐生成任务、查询进度，并从素材库筛选和下载音频。沿用算力中心密钥。

POST/api/music/jobs返回202和job。request_id 必填 UUID，保存后用于查询；Idempotency-Key 如传入必须一致。
GET/api/music/jobs/{request_id}只查询原任务，不重新生成；不存在返回404。

prompt：1～2000字。model：lyria-fast（默认，Lyria 3.5 Fast）、lyria（Lyria 3.5）、lyria-pro（Lyria 3 Pro）、lyria-pro-fast（Lyria 3 Pro Fast）。时长写进提示词，不保证精确时长。

tags：可选字符串数组，最多30个，每个1～80字；style_id：可选1～256字非空字符串。手动标签和画风 ID 原样保存，不传照常生成入库。auto_tags 从提示词自动提取，表示生成要求，不代表音频分析；未识别内容不猜测，不调用额外模型，不覆盖手动标签。

状态：generating生成中、ingesting入库中、recovering恢复原任务、completed已取得结果、unknown待核对。同编号同内容只生成一次，修改标签或画风 ID 也算不同内容，返回400。断线、刷新和重启后只查询原编号，不自动重发。

result.music_tags 和 clips[].music_tags 按 music_style（音乐风格）、music_mood（情绪）、music_instrument（乐器）、music_use（用途）、music_voice（人声）分类；auto_tags 平铺列表保留兼容。素材库可用同名参数叠加筛选，例如 kind=audio&music_instrument=钢琴&music_mood=舒缓。result.clips：音频/WAV地址和标签；result.library：入库回执，含asset_id、path、kind、ok。result.ingested 是文件数。completed若带ingest_error或ingested=0，表示音乐已有结果但入库未完成，不能为了入库重复生成。

GET /api/library?kind=audio&tag=钢琴 可筛选标签，叠加style_id精确筛选画风ID；参数使用URL编码。GET /api/library/{asset_id} 查详情，GET /api/library/{asset_id}/file 带同一密钥下载。优先使用入库路径，外部音频地址可能过期。

统一 API 不开放音乐账号管理、就绪操作、同步generate或jobs/latest。手动标签和画风 ID 保存在原任务，重启恢复不会丢失。

素材列表可用 audio_category 筛选音乐、音效或其他，用 duration_min、duration_max 按实际秒数筛选，包含边界，可只填写一端。可叠加标签与画风 ID。

音频素材详情返回 duration（实际秒数，未读取时为 null）与 audio_category（music 音乐、sound_effect 音效、other 其他）。
