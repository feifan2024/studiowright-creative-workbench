01

接入准备

先连接工作台，再读取真实可用的账号、项目与模型。

访问与密钥

先在上方创建统一密钥。地址中的 127.0.0.1 指运行调用程序的电脑；Windows 需保持工作台的 SSH 转发，Ubuntu 本机使用同一地址。统一接口不是 OpenAI 兼容接口，不要直接开放到公网。

每次请求在 Authorization 请求头中携带 Bearer 加密钥。所有密钥均有读取和生成权限；管理页面及工作台端口只供可信本机使用。Flow 原后台保留自己的独立密钥。

Python 公共准备

以下示例使用 Python 标准库。先把创建的密钥设置为环境变量 STUDIOWRIGHT_API_KEY，再将公共准备与需要的示例放在同一脚本中。只复制或浏览本页不会发起请求。

Windows PowerShell 可以输入 $env:STUDIOWRIGHT_API_KEY = Read-Host '输入统一密钥'；Ubuntu 终端可以输入 read -s STUDIOWRIGHT_API_KEY; export STUDIOWRIGHT_API_KEY 后输入密钥。只在可信环境中使用。

Python · 放在脚本开头
import json
import os
import uuid
from pathlib import Path
from urllib.request import Request, build_opener, ProxyHandler
from urllib.error import HTTPError

BASE = "http://127.0.0.1:18922"
API_KEY = os.environ["STUDIOWRIGHT_API_KEY"]
client = build_opener(ProxyHandler({}))

def call(path, payload=None, request_id=None):
    headers = {"Accept": "application/json", "Authorization": "Bearer " + API_KEY}
    body = None
    if payload is not None:
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        headers["Content-Type"] = "application/json"
        if request_id:
            headers["Idempotency-Key"] = request_id
    request = Request(BASE + path, data=body, headers=headers)
    try:
        with client.open(request, timeout=180) as response:
            return json.load(response)
    except HTTPError as error:
        try:
            detail = json.load(error).get("error", "请查询原请求记录")
        except (ValueError, AttributeError):
            detail = "请查询原请求记录"
        raise RuntimeError(f"请求失败（HTTP {error.code}）：{detail}") from error

只读查看账号、项目和模型

账号列表中的 key 带 flow-account- 前缀；手动指定 Gemini 账号时，使用去掉前缀后的部分。Flow 使用项目的完整 key。模型 ID 从各账号及 Flow 模型列表读取，以实际返回为准。

state = call("/api/snapshot")
for account in state["real_accounts"]["items"]:
    print("Gemini 账号:", account["key"][len("flow-account-"):],
          account.get("label"), account.get("gemini"),
          account.get("gemini_model_options", []))
for project in state["projects"]:
    print("Flow 项目:", project["key"], project["title"], project["source_profile"])
print("Flow 模型:", state["flow_models"])
02

Gemini 对话与推理

通过统一账号池调用已核对的 Gemini，支持独立提问和保留上下文的对话。

POST/api/real-pool/chat真实调用，可能产生费用

account 可填 auto 自动选择，或填已核对账号的标识。自动选择会依据账号状态和额度规则；已绑定对话继续使用原账号。prompt 不能为空，最多 20,000 字。每条新消息生成一个 UUID，并在请求头 Idempotency-Key 中传入。

单次文本提问

这是独立提问，不保留对话上下文。脚本执行前请确认调用内容和费用；请求编号先打印出来，便于结果未确认时查询。

Python · 真实推理
request_id = str(uuid.uuid4())
print("请保存本次请求编号:", request_id, flush=True)
result = call("/api/real-pool/chat", {
    "account": "auto", "prompt": "请概括这段文字的重点。", "attachments": []
}, request_id)
print(json.dumps(result, ensure_ascii=False, indent=2))
# 未收到返回时，使用已保存的同一个编号查询；不要再次提交新请求。
# print(call("/api/real-pool/requests/" + request_id))

多轮对话与模型选择

先创建对话，再传入返回的 id。可选模型来自账号上次核对结果；省略 model 使用默认选择。后续消息沿用 conversation_id 和原账号，每条消息使用新的请求编号。

Python · 新建对话并发送第一条消息
conversation = call("/api/conversations", {"title": "我的对话"})
conversation_id = conversation["id"]
request_id = str(uuid.uuid4())
print("对话编号:", conversation_id, "请求编号:", request_id, flush=True)
payload = {"account": "auto", "prompt": "你好，请介绍你的能力。",
           "conversation_id": conversation_id}
# 需要指定模型时取消下一行注释，并填入实际模型 ID。
# payload["model"] = "填写账号模型列表中的 ID"
result = call("/api/real-pool/chat", payload, request_id)
print(json.dumps(result, ensure_ascii=False, indent=2))

图片、视频和 PDF 附件

先用同一个请求编号上传附件，再将每次上传返回的对象放入 attachments。最多 4 个、总计不超过 100 MB；支持 jpg、jpeg、png、webp、mp4、mov、webm、pdf。上传只是暂存，发送对话时才会交给 Gemini。

Python · 单个附件示例
file = Path("替换为本地文件路径.jpg")
extension = file.suffix.lower().lstrip(".")
request_id = str(uuid.uuid4())
print("请保存本次请求编号:", request_id, flush=True)
upload = Request(BASE + "/api/real-pool/uploads/" + request_id + "/0/" + extension,
                 data=file.read_bytes(), method="POST", headers={
                     "Content-Type": "application/octet-stream",
                     "Authorization": "Bearer " + API_KEY})
with client.open(upload, timeout=180) as response:
    attachment = json.load(response)
result = call("/api/real-pool/chat", {
    "account": "auto", "prompt": "请分析这个附件。", "attachments": [attachment]
}, request_id)
print(json.dumps(result, ensure_ascii=False, indent=2))

返回 completed 时，文本在 response；如有已保存图片，images 给出工作台内的读取路径。dispatching 为处理中，failed 查看 note，unknown 需要先核对。当前接口返回 JSON，并非流式接口。

使用已登记的 Flow 项目；项目决定首次执行账号。

POST/api/real-pool/flow真实生成，可能消耗积分

从接入准备中的只读列表取得 project_key 和对应类型的真实模型 ID。confirm 必须为 true。当前工作台接口提供文生图、文生视频；项目、模型与参数应先核对。

Python · 提交一张图片
request_id = str(uuid.uuid4())
print("请保存本次请求编号:", request_id, flush=True)
payload = {
    "project_key": "填写已登记项目的完整 key", "kind": "image", "confirm": True,
    "params": {"prompt": "阳光下的现代办公室", "model": "填写图片模型 ID",
               "aspect": "16:9", "count": 1, "resolution": "720p",

result = call("/api/real-pool/flow", payload, request_id)

文生视频

Python · 提交视频
request_id = str(uuid.uuid4())

    "params": {"prompt": "阳光照进安静的办公室，镜头缓慢前移",
               "model": "填写视频模型 ID", "aspect": "16:9", "count": 1,
               "resolution": "720p", "duration": 8, "max_credits": 0}

result = call("/api/real-pool/flow", payload, request_id)

图片比例16:9、4:3、1:1、3:4、9:16

查询提交与生成结果

先用请求编号查询工作台记录。submitted 仅表示已经交给 Flow 排队；再使用返回的 task_id 在快照的最近任务中查找执行状态和 downloads。快照仅包含最近 150 条任务。

Python · 查询已提交的任务
record = call("/api/real-pool/flow-requests/" + request_id)
print("提交记录:", record)
if record.get("task_id"):
    state = call("/api/snapshot")
    tasks = [t for t in state["tasks"] if t["source_id"] == record["task_id"]]
    print("原任务:", tasks)  # 可能包含状态、关联重试和 downloads

任务成功后，使用返回的 downloads[].path 加统一 API 地址和同一把密钥下载文件。列表为空代表暂时没有可下载文件。

Python · 下载已完成的文件
download_path = tasks[0]["downloads"][0]["path"]
request = Request(BASE + download_path, headers={"Authorization": "Bearer " + API_KEY})
with client.open(request, timeout=180) as response:
    Path("生成结果").write_bytes(response.read())
04

接口与状态

查询不等于重新提交；超时也不等于任务没有执行。

接口作用
GET /api/health工作台健康状态。
GET /api/snapshot读取当前账号、项目、模型及最近任务。
POST /api/conversations创建对话；字段 title。
GET /api/conversations/{id}读取该对话与消息记录。
POST /api/real-pool/chat提交 Gemini 消息，可带附件和对话编号。
GET /api/real-pool/requests/{请求编号}查询一次 Gemini 请求与回复。
POST /api/real-pool/flow提交图片或视频生成。
GET /api/real-pool/flow-requests/{请求编号}查询 Flow 的提交记录和原任务编号。

每条新请求使用新的 UUID；同一次请求需要保留原编号和原始参数。遇到超时、断线或 unknown 时，先查原记录与关联任务，不要换编号重复生成。账号或对话尚未核对、参数不正确时，读取返回的 error 并处理。
