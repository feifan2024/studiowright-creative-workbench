1. 连接试用服务

使用旧后台「设置 → API Key」里的密钥。这里不填写管理员 Token。密钥只保留在当前页面内存，刷新后重新填写。

尚未连接。页面不会自动检测登录或生成内容。

2. 导入一个独立试用账号

不要把旧服务中仍启用的同一个账号放进来并行使用。HTTP 连接不加密，仅在可信局域网操作。


登录检查通过后才能读取真实模型。不会显示猜测的模型名称。
