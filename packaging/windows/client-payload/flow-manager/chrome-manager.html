首次安装或更新插件

  1. 勾选账号，点击“安装／重新加载插件”，会打开各自的扩展管理页。
  2. 未安装：打开右上角“开发者模式”，点击“加载已解压的扩展程序”，选择下面的文件夹。已安装：找到当前后台对应的账号助手，点一次“重新加载”。
  3. 回到本页点击“连接并采集同步所选账号”。若需要登录，在对应 Flow 窗口中完成登录后，再同步。

安装需要 Chrome 确认，不会静默修改浏览器配置。如插件尚未连接，请安装／重新加载后，在本页手动重新发起同步。最终结果请以“Ubuntu 登录核对成功”为准。
