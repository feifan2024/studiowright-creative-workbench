# v0.2.3 源码发布说明

本版归档工作台、统一 API、Flow 与 Gemini 的近期修复。功能清单见[版本记录](../CHANGELOG.md)，调用和恢复规则见 [API](API.md) 与[运行拓扑](WORKFLOW.md)。

## 验证

- 30 项 Python 回归检查、9 项账号界面检查及工作台 JavaScript 语法检查通过。发布检查使用隔离记录或模拟提交，不调用生成服务。
- 发布前对照线上快照。收录对话汇总最近七天的口径；服务器专用网络映射与部署参数留在部署环境。
- 此前已在线验证：Flow 原任务可换号并获得产物；9 个账号读到积分重置时间；Gemini 两个有待核对旧请求的账号使用原凭据独立验活成功，恢复接新单，原请求状态与尝试次数保持不变。这些验证仅覆盖当时的原任务及账号状态。

## 发布范围

这是源码版本。没有重建或替换 Windows、Ubuntu 安装包，也没有重新安装生产服务。运行数据库、账号授权、密钥、实际网络映射、素材和对话记录均不纳入版本。
