# v0.2.2 源码发布说明

日期：2026-11-08。基于 v0.2.1，收录当前线上程序和尚未发布的 Windows 连接改进。此标签发布源码，不替换旧安装包；页面版本号仅在本源码中更新。

## 主要变化

- 生图 API 允许省略 `max_credits`，兼容旧请求，避免在任务登记前触发异常。
- 账号页先建立状态变量再绘制卡片，修复已经取得数据却一直显示“正在读取”的问题。
- 输入前等待窗口和输入框布局稳定，等待真实鼠标事件并按观测位置有限纠正；无观测或焦点丢失时停止。
- 同步线上原任务与内部尝试关联、长提示词输入、Omni 模型参数、余额读取、账号状态与 Gemini 调用实现。调用参数和积分行为见 [API 文档](API.md)。
- Windows 桌面端收录 SSH.NET 连接支持、首次服务器指纹核对、依赖哈希校验和许可文件；密码不保存。
- 增加 [运行拓扑](WORKFLOW.md)、源码版本文件 `VERSION` 和更新后的 `snapshot-manifest.json`。

## 验证

发布检查使用仓库中的打包源码，不连接生成服务：

```powershell
python -m unittest discover -s tests -p 'test_*.py'
node tests/account_visuals.test.cjs
node --check packaging/ubuntu/snapshot/workbench/app.js
```

- 6项 Python 检查通过：缺省/空值/零积分参数兼容与重复请求保护；鼠标事件延迟、偏移纠正、缺少观测、焦点丢失和布局稳定。
- 3项界面检查通过：用量显示、冷却倒计时，以及不同就绪状态下账号卡片的绘制。
- 92个快照 Python 文件语法检查通过；工作台 JavaScript 语法检查通过。
- Windows `Desktop.cs` 和 `PanelSsh.cs` 与已准备的依赖编译通过；没有安装或启动编译产物，也没有重建安装包。
- 174个快照文件的 SHA256 记录于 `packaging/ubuntu/snapshot/snapshot-manifest.json`；清单不包含自身。

此前在当前部署上完成的线上验证：9个账号的有效项目通过窗口归属、系统焦点和输入框操作检查；账号页修复后显示全部9个账号。用户授权的一批5个图片任务实际重试后4个成功，文件下载和解码通过；另1个等待240秒无图片回复，保留待核对。本次发布检查没有再次调用生成。

## 限制

- 不把接口正常或参数校验通过视为生成必然成功；Google 仍可能拒绝或超时。
- 有旧项目链接失效；没有删除旧项目或把它们标记为恢复可用。
- 不提供新的 Windows/Ubuntu 安装包，不声称本版完成全新安装或完整端到端验收。
- 仓库不包含运行数据库、账号登录资料、密钥、生成素材和对话记录。
