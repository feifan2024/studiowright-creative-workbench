# 安装说明

## Ubuntu 服务端

下载 `StudioWright-Ubuntu-LAN-Setup.run` 到目标 Ubuntu，在终端按实际情况运行：

```bash
# 复用已运行的服务，并启用独立的局域网发现服务
bash StudioWright-Ubuntu-LAN-Setup.run --mode reuse --enable-discovery

# 或在全新环境安装
bash StudioWright-Ubuntu-LAN-Setup.run --mode new
```

复用模式会先核实现有服务，不覆盖已有账号、素材或记录。全新安装发现已有程序或数据时会停止。支持 Ubuntu x86-64，具体依赖见安装包内说明。

## Windows 桌面操作端

运行 `StudioWright-Windows-Desktop-Setup.exe`，按需勾选「在桌面创建快捷方式」，再点击「安装到当前用户」。启动后选择同一局域网内的 Ubuntu 并连接；首次连接需要核对 SSH 服务器身份并按提示完成登录。

窗口关闭或最小化后可在系统托盘找回。若找不到 Ubuntu，请检查两台电脑是否在同一局域网及 UDP 18925 是否可用，也可手动填写地址和 SSH 信息。Windows 需安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

安装包不包含原有账号、登录资料、密钥、素材或历史记录；迁移数据需单独处理。
