# 安装说明

源码构建、服务配置与故障排查见 [Windows 与 Ubuntu 部署手册](DEPLOYMENT.md)。

## Ubuntu 服务端

在 GitHub Releases 下载版本化的 `StudioWright-Ubuntu-24.04-Setup-*.run`。以下命令用 `setup.run` 代表下载的文件名。在 Ubuntu 24.04 桌面版（x86-64、GNOME 46）中，以普通桌面用户打开终端。

```bash
# 复用已运行的服务，并启用独立的局域网发现服务
bash setup.run --mode reuse --enable-discovery

# 或在全新环境安装：先安装系统依赖，并事先安装 Chrome
bash setup.run --mode system-deps
bash setup.run --mode new --keep-awake-on-ac
```

复用模式会先核实现有服务，不覆盖已有账号、素材或记录。全新安装发现已有程序或数据时会停止。支持 Ubuntu x86-64，具体依赖见安装包内说明。

全新安装会配置 Flow、算力中心和统一 API 的用户级自启动，并安装 GNOME 窗口定位扩展、桌面输入助手和桌面登录后的 Flow 恢复服务。请在安装后退出并重新登录 GNOME，按 Ubuntu 提示授权桌面输入，再接入 Flow 账号。Gemini 需单独安装官方 Antigravity CLI，完成 Google 授权并接入账号池。

`--mode system-deps` 需要网络和管理员权限，会从 Ubuntu 仓库安装系统依赖（含 SSH 服务，以供 Windows 桌面端连接）。`--keep-awake-on-ac` 会关闭当前 GNOME 用户的桌面空闲计时及接电自动休眠。想沿用系统电源策略时省略该选项。

## Windows 桌面操作端

运行 `StudioWright-Windows-Desktop-Setup.exe`，按需勾选「在桌面创建快捷方式」，再点击「安装到当前用户」。在「连接 Ubuntu 工作台」里选择服务器，填写 Ubuntu 用户名和密码，再点「连接工作台」。首次用密码连接时，先与管理员提供的服务器指纹核对；密码只用于当前登录，不会保存。已经配置好 SSH 密钥并信任服务器的用户可将密码留空。

桌面端每 5 秒检测连接，断开后自动重连，失败时最多间隔 30 秒再试。密码连接可在当前程序运行期间重连，退出后不保存密码；已有 SSH 密钥配置会自动复用。页面断线时显示提示并保留草稿，恢复后重新读取状态，不自动补发任务。升级正在运行的客户端后，需从托盘退出并重新打开一次。

窗口关闭或最小化后可在系统托盘找回。若找不到 Ubuntu，请检查两台电脑是否在同一局域网及 UDP 18925 是否可用，也可手动填写地址和 SSH 信息。Windows 需安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

安装包不包含原有账号、登录资料、密钥、素材或历史记录；迁移数据需单独处理。
